# Getting help

Thanks for using HydraMind. Here is where to go:

| You want to... | Go to |
|---|---|
| Learn how it works | [README](README.md) and the [docs](docs/README.md) |
| Report a bug | [Bug report form](https://github.com/himanshu748/hydramind/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request form](https://github.com/himanshu748/hydramind/issues/new?template=feature_request.yml) |
| Fix or improve docs | [Documentation form](https://github.com/himanshu748/hydramind/issues/new?template=documentation.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md). Do not post details publicly. |
| Fix a problem in HydraDB itself | [HydraDB issues](https://github.com/hydra-db/hydradb/issues) |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening an issue, please search
[existing issues](https://github.com/himanshu748/hydramind/issues?q=is%3Aissue). Include
your OS, Python version, HydraMind version or commit, HydraDB commit, and the exact
error from stderr. Remove tokens before posting.

HydraMind is maintained by volunteers, so responses may take a few days.
